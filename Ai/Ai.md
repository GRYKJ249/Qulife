# Qulife AI

واجهة المحادثة متصلة بنقطة خادم `/api/ai/chat`؛ يستدعي الخادم واجهة Chat Completions ويعيد الرد إلى المحادثة. لا تضع مفتاح الخدمة في JavaScript أو HTML أو ملفات الواجهة.

## تشغيل المعاينة

يتطلب Node.js 18 أو أحدث. اضبط المتغيرات في بيئة الخادم فقط ثم شغّل:

```sh
OPENAI_API_KEY="مفتاحك" OPENAI_API_BASE="https://api.openai.com/v1" QULIFE_AI_MODEL="gpt-5-mini" npm run dev:preview
```

يستخدم الخادم `gpt-5-mini` افتراضيًا، ويقبل إعداد نموذج آخر عبر `QULIFE_AI_MODEL`. يحدّ الخادم حجم المحادثة وعدد الرسائل، ويطبق حدًا بسيطًا للطلبات من كل عنوان IP.

في نشر الواجهة والخادم بشكل منفصل، وجّه المسار `/api/ai/chat` من نطاق الموقع إلى خادم Node. نقطة API موجودة أيضًا في `server/src/server.ts` وتستخدم متغيرات البيئة نفسها.

المحادثة تُرسل إلى مزود النموذج كي ينشئ الرد، وتُحفظ نسخة محلية من الرسائل في `localStorage` على الجهاز. لا يُضمّن هذا المشروع أي مفتاح API.
